# Design-a-digital-circuit-Implementing-F-Verilog.
Designed a digital circuit that implements a Boolean function, (SOP) terms corresponds to each digit of my roll number (2009018).  Implemented the circuit for F Verilog using the following modeling styles: 
1.Gate level modeling, 
2.Dataflow modeling, 
3.Behavioral modeling
4.Switch-level (CMOS) modeling with its testbench.
